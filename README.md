# Gala Čado — Portfolio

Personal portfolio site, coded from scratch: plain HTML/CSS, no build step, no framework. 

Hosted on Cloudflare Pages; live at [gala-cado.pages.dev](https://gala-cado.pages.dev).

## Structure

```
index.html          Homepage
pages/               resume, projects listing, contact, and projects/ (one page per project)
images/              artefacts
style.css            shared styles
```
