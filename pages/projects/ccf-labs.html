Memory Forensics · Incident Reconstruction

Memory & Disk Forensics

University of Amsterdam · Cybercrime & Forensics

Investigated a system image with Volatility and Scalpel, reconstructing a timeline of user activity.

Overview

Given disk and memory images from a simulated incident, the task was to reconstruct what actually happened on the machine: which processes ran, what the attacker did, and what evidence could be recovered even after files had been deleted.

Approach

  • Used Volatility to enumerate running and hidden processes, active network connections, and injected code within the memory image.
  • Used Scalpel for file carving to recover deleted files directly from the disk image.
  • Cross-referenced timestamps across the registry, filesystem, and memory artifacts to build a coherent timeline of activity.
  • Documented findings and chain of custody in a formal forensic report.

Outcome

The investigation identified clear indicators of compromise and allowed a full reconstruction of the attacker’s actions on the system, from initial access to the artifacts left behind.
