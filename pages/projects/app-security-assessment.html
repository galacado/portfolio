Mobile App Security Assessment

University of Amsterdam · Security of Systems & Networks

Security risk assessment of a mobile/web app covering access control, transport encryption, and API security.

mobile security api security transport security risk assessment

Overview

A structured security assessment of a mobile/web application, evaluated it against common categories of risk rather than looking for a single exploit — closer to how a real assessment engagement is scoped.

Approach

  • Reviewed authentication and access-control logic for privilege-escalation flaws.
  • Tested the transport-layer security configuration, including certificate validation and supported TLS versions.
  • Analysed the backend API for injection flaws and broken object-level authorization (IDOR-style access checks).
  • Produced a risk-rated report of findings with concrete, prioritised recommendations.
