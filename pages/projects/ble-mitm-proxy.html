Bluetooth LE MITM Proxy

University of Amsterdam · Advanced Security

Built a proxy that intercepted and modified live Bluetooth Low Energy device traffic in real time.

python bluez / d-bus ble mitm

Overview

Many BLE peripherals trust a paired connection implicitly, with little verification of the data flowing over it. For this assignment I built a GATT-level man-in-the-middle proxy that sat between a BLE peripheral and its companion app, relaying traffic transparently by default and selectively rewriting it on the fly.

Approach

  • Used BlueZ and D-Bus on Linux to advertise a cloned GATT server while simultaneously connecting to the real peripheral as a client.
  • Forwarded characteristic reads and writes transparently between both sides by default.
  • Intercepted specific characteristics to alter values in transit — spoofing sensor data and bypassing simple authentication checks.
  • Tested the proxy against a real BLE peripheral to confirm the attack worked outside of a purely theoretical setup.

Takeaway

The exercise demonstrated how easily BLE connections can be intercepted when devices did not pair with proper encryption and mutual verification — a gap that was still common in consumer IoT hardware.
