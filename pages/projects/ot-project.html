Heap Exploitation · Privilege Escalation

CVE-2021-3156 Reproduction

University of Amsterdam · Offensive Technologies

Reproduced and analysed a heap-based buffer overflow in sudo, then validated the official patch as mitigation.

Overview

CVE-2021-3156 (“Baron Samedit”) is a heap-based buffer overflow in sudo’s command-line argument parsing, triggered through how sudo handles escaped characters when running in shell mode. The bug allows any local user to escalate to root, without needing to be listed in the sudoers file. For this assignment I reproduced the vulnerability end to end: understanding the flaw, exploiting it, and confirming the fix.

Approach

  • Set up an isolated VM running a sudo version vulnerable to CVE-2021-3156.
  • Studied the vulnerable code path in sudo’s argument parser to understand exactly how the overflow is triggered.
  • Crafted a proof-of-concept input that overflows the heap buffer in a controlled way.
  • Used gdb and pwndbg to trace the heap corruption step by step and confirm escalation to a root shell.

Validating the patch

After confirming the exploit worked, I applied the official patched version of sudo and reran the same proof-of-concept. The overflow no longer occurred, and I documented the difference in behaviour before and after patching as part of the writeup.
